Setting up virtual environment from scratch on linux system/bash:

Update ubuntu/linux system packages:
sudo apt update

Upgrade ubuntu/linux system packages (If you need upgrade):
sudo apt upgrade

Combined:
sudo apt update && sudo apt upgrade

Check python version:
python3 --version

If no python installed, install python:
sudo apt install python3

Install python virtual environment package:
sudo apt install python3-venv

Navigate to project folder:
cd ~/my-project

Create virtual environment:
python3 -m venv venv 
(or) 
python3 -m venv .venv

Activate virtual environment:
source venv/bin/activate

-- Virtual environment is ready to go! --

Below are steps to install and manage packages in no particular order:

Install <package name>:
pip install <package name>

Install packages from list/txt file:
pip install -r requirements.txt

Show installed packages:
pip list

Deactivte virtual environment:
deactivate

Create/update requirements.txt:
pip freeze > requirements.txt

Check requirements.txt file:
cat requirements.txt

-- End of package/virtual environment management --

File convention for folders with no content but want to preserve directory structure:
.gitkeep

Setting up Jupyter Notebook in Visual Studio Code:

1. Activate virtual environment in project folder
2. Installation

Ensure pip is updated, if you didn't recently update:
python3 -m pip install --upgrade pip

Install jupyter and (I assume) its kernel:
pip install jupyter ipykernal

3. Create a file in chosen folder with the extention > file.ipynb
4. Viewing the file in vs code, in top right 'select kernel'
5. You will be prompted to install/add python/jupyter extensions > install them
6. Select python environment: Recommended > (broken) venv/python.exe (or something to that effect)

For my computer, I got error message: "Too many changes were detected. Only the first 10000 changes will be shown below."
= vs code file watcher sees too many files/changes

To fix:
From project root, deactivate venv:
echo "venv/" >> .gitignore
cat .gitignore (to check)

Open vs code project settings (2 ways):
1. Add directly to project by creating folder and file
- Add folder from project root ".vscode"
- Add filename inside .vscode folder "settings.json"
2. Use vs code navigation
- Ctrl + Shift + P
- Search "Preferences: Open Workspace Settings (JSON)"
- The folder and file will be opened and added automatically
3. Put in JSON, the following:

{
    "files.watcherExclude": {
        "**/venv": true
    },
    "files.exclude": {
        "**/venv": true
    }
}

4. Reset vs code (Recommended)
- Note saving changes updated the file watcher, so I don't see venv files in unstaged changes
- I was able to add venv with no errors
